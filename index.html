PriceScanUA

Python / PostgreSQL / Telegram

PriceScanUA is a Telegram bot for tracking grocery prices. It watches Ukrainian supermarkets (ATB, Silpo, Novus, Varus) and notifies you when an item from your list gets cheaper. Build a basket — the bot monitors the stores and tells you where it's cheaper to buy. Built because there is no decent alternative for Ukrainian retail on the market. Stack: Python (aiogram), PostgreSQL, Playwright, APScheduler, Docker, GitHub Actions CI/CD. Self-hosted on a VPS, Telegram Mini App, automatic deploys, daily backups, HTTPS.
